用户是主动学习者：每道题都亲手写代码，遇到不懂会追问"为什么"，修完 bug 会要求总结规律。

**Why:** 这是从被动学习升级为主动掌控的标志 — 不满足于"能跑就行"，而是理解底层原理。

**How to apply:** 教学时保持"先讲概念 → 给代码框架 → 用户动手 → 检查反馈 → 总结规律"的节奏。多留思考空间，不要直接给答案。当用户问"为什么"时，这是他们正在内化的信号，值得深入讲。
